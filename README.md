# Tablero de gestión comercial

Tablero interactivo hecho con Streamlit (TP3 - Visualización de Datos).

## Cómo correrlo

1. (Opcional) Crear y activar un entorno virtual:

   ```bash
   python -m venv venv
   source .venv/bin/activate      # Mac / Linux
   .venv\Scripts\activate         # Windows
   ```

2. Instalar los requerimientos:

   ```bash
   pip install -r requirements.txt
   ```

3. Correr la aplicación desde la terminal (en la carpeta del proyecto):

   ```bash
   streamlit run app.py
   ```

Se abre automáticamente en el navegador (por defecto en http://localhost:8501).
